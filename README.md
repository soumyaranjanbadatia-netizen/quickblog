# Quickblog

Quickblog is a full-stack blogging platform built with React, Vite, Tailwind CSS, Express, MongoDB, and JWT-based authentication.

## Features

- Browse and search blogs
- Blog categories
- Admin registration and login
- Create and manage blog posts
- AI-assisted blog generation
- Image uploads
- Publish and unpublish blogs
- Comment management
- Responsive UI

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Axios

### Backend
- Node.js
- Express
- MongoDB
- Mongoose
- JWT
- ImageKit
- Google Gemini
